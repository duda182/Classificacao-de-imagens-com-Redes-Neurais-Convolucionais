# 🧠 Projeto CNN - Inteligência Artificial

Projeto desenvolvido em Python utilizando Redes Neurais Convolucionais (CNN) para classificação e análise de imagens.

---

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como atividade acadêmica utilizando técnicas de Deep Learning com CNN (Convolutional Neural Network).

O notebook realiza:

- Pré-processamento de dados;
- Construção da rede neural;
- Treinamento do modelo;
- Avaliação de desempenho;
- Visualização de resultados.

---

## 🚀 Tecnologias Utilizadas

- Python
- Jupyter Notebook
- TensorFlow / Keras
- NumPy
- Matplotlib
- Pandas
