# Classificação-de-imagens-com-Redes-Neurais-Convolucionais
Aplicação capaz de classificar imagens em diferentes categorias usando redes neurais concolucionais (CNN)
# Projeto CNN - Inteligência Artificial

Projeto desenvolvido utilizando Redes Neurais Convolucionais (CNN) em Python.

## Tecnologias utilizadas
- Python
- TensorFlow / Keras
- Jupyter Notebook
- NumPy
- Matplotlib

## Objetivo
Criar e treinar um modelo de rede neural convolucional para classificação de imagens.

## Arquivos do projeto
- `A3CNN.ipynb` → notebook principal do projeto

## Como executar

1. Clone o repositório:
```bash
git clone https://github.com/SEUUSUARIO/A3CNN.git
```

2. Instale as bibliotecas:
```bash
pip install tensorflow numpy matplotlib
```

3. Execute o notebook:
```bash
jupyter notebook
```
